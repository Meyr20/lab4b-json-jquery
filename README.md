
# BIC21203 Web Development — Lab 4b

## Introduction
This repository contains my Lab 4b exercises on JSON and jQuery.

## Objectives
- Create and structure JSON data.
- Retrieve and display JSON data using JavaScript Fetch API.
- Use jQuery to modify HTML text, add CSS classes, and handle button click events.

## Question 1: Create and Structure JSON Data
The `books.json` file contains two books:
- The Great Gatsby by F. Scott Fitzgerald
- To Kill a Mockingbird by Harper Lee

Each book includes its title, author, publication year, and genres.

## Question 2: Retrieve and Display JSON Data
The `books.html` file uses the JavaScript Fetch API to retrieve data from `books.json` and display the first book's title, second book's author, and genres of both books.

## Question 3: Compare Native JavaScript and jQuery
The `jquery-dom.html` file demonstrates:
- Changing text to "Modified Text".
- Adding the `myStyle` CSS class.
- Displaying an alert when the button is clicked.

## Project Structure
- `books.json` — JSON book data.
- `books.html` — Fetches and displays JSON data.
- `jquery-dom.html` — Demonstrates jQuery operations.
- `screenshots/` — Screenshots of the exercises.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Run `books.html` and `jquery-dom.html` using Live Server.
3. Ensure an internet connection is available for the jQuery CDN.
